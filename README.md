# Kinvi Open Batch

A working prototype built for Market Maven 2026, Round 2 (The Crisis Response). Kinvi is a fictional company; every figure comes from the case and Inject A.

- **Check your bar:** type a batch code (CC-212, CC-213, CC-214, CC-209) to see its status, tests and complaints, and claim a refund if it is recalled. The "Show status as of" buttons replay how each batch's status changed across the crisis.
- **Recall cost lab:** the crisis team's view. Test any recall plan against the ₹25 lakh fund, using the case's unit costs.

Plain HTML, CSS and JavaScript in one file (`index.html`). No build step.
